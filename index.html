🔗 Share Your Dashboard

GET A LIVE LINK YOUR TEAM CAN CLICK — NO LOGIN NEEDED
1
Upload your latest data first
Use the "Upload Report" button in the top right. Your data gets embedded in memory — then save the HTML file once you're happy with it.
2
Go to Netlify Drop
Open app.netlify.com/drop — it's free, no account needed. Drag and drop this HTML file onto the page.
3
Get your shareable link instantly
Netlify gives you a link like your-name.netlify.app — share it with your team. They open it in any browser, no file download needed.
4
Update anytime
When you have new data — upload fresh Excel here, then drag the HTML file to Netlify again. The same link updates automatically.
5
Hide the upload button before sharing
Click 👁 VIEWER MODE before recording or sharing your screen — it hides the upload button so viewers only see the dashboard.
💡 ASM Filter tip: Once data is loaded, the ASM filter bar appears below the header. Anyone viewing the shared link can click an ASM name to filter all views instantly — Overview, GMD, and all region tabs update in real time.
GITHUB SETUP
Connect to GitHub
Your data will be saved as data.json in your GitHub repo. Viewers load it automatically — no login needed.
Get one at GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → Contents: Read & Write
🚀
Publish to GitHub?
This will overwrite the live data.json in your repo. Everyone with the link will immediately see the new data.
